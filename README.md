# OTelFeature presentation

Landing page for the talk, linked from the slides by QR code: <https://otelfeature.github.io/presentation/>

Edit [`index.md`](index.md); GitHub Pages builds it with Jekyll on every push to `main`. Photos go in `assets/` and replace the GitHub avatar URLs in `index.md`.

The optional blocks (slides button, recording sign-up, booth numbers, session feedback, analytics) are switched on in [`_config.yml`](_config.yml): each one stays hidden while its value is empty. Use a sign-up form that asks for consent per company, since the leads go to Flagsmith and Dash0 separately.

`qr.png` is the QR code for the slide. It encodes the URL above, so it only changes if the URL does.
